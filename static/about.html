SiftGuard haqqında

Dövlət qurumları və banklar üçün nəzərdə tutulmuş vasitə: işçi süni intellektdən istifadə edərkən şəxsi məlumatlar xaricə çıxmır.

SiftGuard nədir

Ad ingiliscə iki sözdən ibarətdir: sift (süzmək) və guard (qorumaq). Loqotipdə qalxanın sol yarısında məlumat axını süzülür, sağ yarısında qorunur.

SiftGuard işçi ilə süni intellekt xidməti arasında yerləşən filtrdir. İşçi mətni daxil edir, SiftGuard mətndəki şəxsi məlumatları tapır və onları [AD_1], [FIN_1] kimi etiketlərlə əvəz edir. Süni intellektə yalnız etiketli mətn göndərilir. Cavab gələndən sonra etiketlər orijinal məlumatlarla əvəz olunur. Rəhbərlik yalnız kateqoriyalar üzrə say göstəricilərini görür, mətnləri yox.

Necə işləyir

  1. Mətni daxil edin. SiftGuard məlumatları tapır və rəngli etiketlərə çevirir.
  2. AI-yə köçürün. Qorunmuş mətni istədiyiniz süni intellekt xidmətinə yapışdırın. Server API açarı ilə işləyirsə, mətn birbaşa da göndərilə bilər.
  3. Cavabı qaytarın. AI-nin cavabını yapışdırın: etiketlər yerinə qaytarılır. Etiketin yazılışı bir qədər dəyişsə belə, proqram onu tanıyır və xəbərdarlıq göstərir.

Axtarış iki hissədən ibarətdir: qaydalar (nümunələr, yoxlama cəmləri, ad lüğəti) və yerli süni intellekt modeli (adlar, ünvanlar, tarixlər). Model yalnız bu serverdə işləyir, mətn heç bir yerə göndərilmir. Model olmadıqda yalnız qaydalar işləyir.

Hansı məlumatlar qorunur

  • FİN, şəxsiyyət vəsiqəsinin nömrəsi, VÖEN;
  • IBAN (mod-97 yoxlaması) və bank kartı (Luhn yoxlaması);
  • telefon nömrələri və e-poçt ünvanları;
  • ad, soyad və ata adı;
  • ünvanlar və tarixlər.

Məlumatlar boşluqlarla, defislərlə, nöqtələrlə, sətir keçidləri ilə bölünəndə, oxşar kiril hərfləri və qarışıq registrlə yazılanda da tapılır.

Qrifli sənədlər

«Məxfi», «Tam məxfi», «Gizli», «Xidməti istifadə üçün» və «XİÜ» qrifləri olan mətn tam bloklanır: maskalanmır və süni intellektə göndərilmir. İdarəetmə panelində vaxt, qrif kateqoriyası və kanal göstərilən qırmızı kritik bildiriş yaranır. Sənədin mətni heç yerdə saxlanmır.

Məxfilik prinsipləri

  • Mətn və etiket cədvəli serverdə saxlanmır və qeydə alınmır.
  • Etiket cədvəli yalnız brauzer səhifəsinin yaddaşındadır və səhifə bağlananda silinir.
  • API açarı yalnız serverdə saxlanır.
  • Sorğuların sayı və mətnin uzunluğu məhdudlaşdırılıb, xəta mesajlarında mətn təkrarlanmır.
  • İdarəetmə paneli standart olaraq yalnız serverin işlədiyi kompüterdən, uzaqdan isə token ilə açılır.

Məhdudiyyətlər

  • SiftGuard bütün məlumatları tapmağa zəmanət vermir. Tanış olmayan ad, qeyri-adi yazılış və ya sərbəst formada yazılmış məlumat gözdən qaça bilər.
  • Model azərbaycan dilində yazılmış mətn üçün hazırlanıb, rus dilində daha az dəqiqdir. Bütün tarixlər maskalanır, yalnız doğum tarixləri yox.
  • Modelin lisenziyası kommersiya məqsədi ilə istifadəyə icazə vermir (CC BY-NC 4.0).
  • Süni intellekt xidməti yalnız etiketli mətni alır, lakin həmin xidmətin öz şərtləri tətbiq olunur.
  • İstifadəçi girişi və rollar hələ yoxdur: giriş şəbəkə səviyyəsində məhdudlaşdırılmalıdır.
