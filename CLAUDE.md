# Süzgəc — проект на OYU CyberAI Hackathon 2026

## Идея
Шлюз между сотрудником организации и AI-ассистентом. Сотрудник вставляет
текст. Süzgəc находит азербайджанские персональные данные, заменяет их
метками ([FIN_1], [AD_1]…), отправляет в LLM замаскированный текст и в
ответе возвращает исходные значения. Реальные данные не уходят в AI.
Руководство видит только статистику по категориям, не тексты.

## Что находим
- FİN (7 символов, буквы+цифры), номер удостоверения (AZE+8 цифр, AA+7 цифр)
- VÖEN (10 цифр, по контексту), AZ IBAN (28 символов, проверка mod-97)
- Банковская карта (16 цифр, проверка Луна), телефоны +994 / 0XX
- Email, ФИО (словарь имён + суффиксы -ov/-ova/-yev/-yeva/-li/oğlu/qızı)
- Адреса и даты, а также ФИО вне словаря: локальная модель LocalDoc/pii-ner-azerbaijani-v4 (необязательная,
  CC BY-NC 4.0, только локально на сервере). Гибрид: правила + модель, у каждой находки виден источник
- Защита от обхода: разбиение пробелами/дефисами/точками/переносами, кириллические двойники, регистр,
  невидимые символы
- Текст с грифом («Məxfi», «Tam məxfi», «Gizli», «Xidməti istifadə üçün», «XİÜ») блокируется целиком,
  не маскируется; в панели администратора (/admin) красное уведомление: время, категория, канал, без текста
Форматы потом сверим с официальными источниками.

## Стек
Python 3.11, FastAPI, uvicorn, pydantic, Anthropic SDK, pytest,
обычный HTML/JS (без фреймворков). Модель LLM — из переменной окружения.
Необязательно: PyTorch + transformers для локальной модели поиска данных (requirements-ai.txt).

## Режимы
1. Основной — «копировать и вставить»: без ключа API. Замаскировать → скопировать → вставить в
   любой AI → вставить ответ обратно → восстановить в браузере. Таблица меток только в памяти вкладки.
2. Встроенный AI — второй режим, виден только если задан ключ API.

## Эндпоинты
- POST /api/mask — основной режим: вернуть замаскированный текст и позиции (значения не возвращаются)
- POST /api/check — найти данные, вернуть категории и позиции
- POST /api/chat — замаскировать → LLM → вернуть ответ с исходными данными (только с ключом)
- GET /api/config — доступен ли встроенный AI
- GET /api/stats — только счётчики по категориям

## Безопасность (оценивается жюри, 25 баллов)
- Исходный текст и таблица меток живут только в памяти запроса, не сохраняются
- Ключ API только в .env (.env в .gitignore, никогда не коммитить)
- Текст пользователя передаётся в LLM как данные в тегах, не как инструкция
- Лимит длины ввода, понятные ошибки
- Без ключа API основной режим «копировать и вставить» работает полностью; встроенный AI скрыт
- Тесты только на синтетических данных, никаких реальных людей

## Демо (2 минуты из 5)

(замаскированный текст + ответ с восстановленными данными), ниже статистика.
