SiftGuard: a gateway between an employee and an AI assistant. It finds Azerbaijani personal data in text, images and
PDF documents, replaces it with labels or black bars, sends only the protected version to the AI and restores the
values in the answer. Source code: https://github.com/Eras3rX/Suzgec
